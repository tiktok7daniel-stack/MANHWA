## 1. عن المستخدم والمشروع

- **المستخدم بيكلمك بالعربي المصري، والرد يكون بالعربي المصري، وبسيط.**

  - اسمه MANHWA، وفي الشاشة الافتتاحية MANHWA LEGENDS.
  - أصله Mihon / TachiyomiAT.

  - **ملاحظة:** رقم الـ IMEI بتاع الموبايل ظهر في سكرين شوت. نصحت المستخدم ما يشاركهوش.

## 2. قواعد الشغل (لازم تتطبق دايماً)

1. **الرد بالعربي المصري.**
2. **الأيقونات Material Symbols بس** (`mihon.icons.materialsymbols.*`)، **وممنوع الإيموجي جوه التطبيق.**
   - لو أيقونة مش موجودة: SVG من `google/material-design-icons`، يتحط في `icons/material-symbols/src/main/valkyrieResources/rounded/`.
3. **التصميم ManhwaKit** الزجاجي المتوهج:
   - الأدوات: `glass()`، و`ManhwaKit.NeonButton`، و`GhostButton`، و`TopBar`، و`IconOrb`، و`GlowIcon`.
   - الألوان: Ember `#FF6A2B`، وMint `#3DDC97`، وAmber `#FFB020`، وأحمر `#FF4D6A`.
4. **ممنوع حذف أي ميزة موجودة، وممنوع حذف بيانات المستخدم.** أي حقل جديد يكون بقيمة افتراضية متوافقة مع القديم.
5. **لينك البناء يتبعت كلينك artifact** (arm64 جوه الـ zip).
6. **قيود أمان، بنصها:**
   - "لا تستخدم مفاتيح API منشورة أو مسروقة."
   - "لا تنشئ حسابات وهمية."
   - "لا تتجاوز CAPTCHA أو أنظمة الحماية."
   - "لا تدّعي أن GitHub Actions نجح أو أن الدمج تم أو أن APK أصبح متاحًا إلا بعد تنفيذ ذلك فعليًا والتحقق من النتيجة."
   - "إذا كانت هناك صلاحيات أو خدمة خارجية لا يمكن الوصول إليها من بيئة التنفيذ، اذكر العائق بدل اختلاق نتيجة."
   - "لا تضع Mock بدل النظام الحقيقي إلا داخل الاختبارات."
   - "لا تحذف البيانات الموجودة."
7. **توكن Hugging Face** اللي المستخدم لصقه في الشات مرة: **ما يتستخدمش أبداً وما يتحطش في أي ملف.** والتطبيق بيستخدم التوكن اللي المستخدم بيكتبه بنفسه جوه التطبيق.
8. **Scrapling** وأي حاجة بتتخطى الحماية أو الـ CAPTCHA **اترفضت وما اتضافتش.**

### 2.1 قاعدة البناء (طلب المستخدم يوم 17 أكتوبر)
- **ما تعملش بناء بعد كل طلب.** نفّذ الطلب، وسجّله في `docs/PENDING_CHANGES.md`، واعمل commit وpush ومعاه `[skip ci]` في الرسالة.
- **البناء يتعمل بس لما المستخدم يقول "اعمل بيلد نهائي".** ساعتها:
  1. شغّل `build_branch.yml` بـ workflow_dispatch على الفرع (أداة GitHub MCP `actions_run_trigger`).
  2. لو نجح، اعمل fast-forward لـ main:
     ```bash
     git fetch -q origin main && git merge-base --is-ancestor origin/main <sha> && git push origin <sha>:main
     ```
  3. ابعت لينك arm64، ومعاه ملخص كل اللي في القايمة.
  4. فضّي القايمة.

## 3. البيئة والأدوات (مهم للشات الجديد)

- **مفيش `gh` CLI.** أي حاجة على GitHub بتتعمل بأدوات `mcp__github__*`:
  - `actions_run_trigger`، و`actions_list`، و`actions_get`، و`get_job_logs`.
- **قراية سجل بناء فشل:** `get_job_logs` مع `return_content` و`tail_lines` كبير، وبعدها دوّر على `' e: '` (أخطاء Kotlin).
- **CI** (`.github/workflows/build_branch.yml`):
  - **بيشتغل لوحده** مع أي push على `claude/**`، إلا لو الـ commit فيه `[skip ci]`.
  - **concurrency:** أي push جديد بيلغي البناء اللي شغال.
  - **الخطوات:**
    1. `assembleDebug`.
    2. Show errors.
    3. Upload build log.
    4. Verify app name.
    5. **Check the APKs can be installed:** apksigner، وzipalign -c -P 16، وaapt2 badging، والمكتبات الأصلية.
    6. رفع الـ artifact `MANHWA-build-N`.
    7. `:app:testDebugUnitTest`.
  - البناء بياخد حوالي 15 لـ 40 دقيقة. لو علّق أكتر من 40 دقيقة في خطوة Build، الغيه وأعد تشغيله.
- **حاجات مقفولة من بيئة التطوير:**
  - Hugging Face، وModelScope، وdl.google.com، وmaven.google.com، وskills.sh.
  - تحميل الـ artifacts مباشرة.
- **النصوص (Moko):**
  - بتتضاف في `i18n-at/src/commonMain/moko-resources/base/strings.xml` (الإنجليزي) و`.../ar/strings.xml` (العربي).
  - الاستخدام: `ATMR.strings.<key>`.
  - كنت بستخدم سكريبت صغير بيقرا سطور شكلها `key|en|ar` ويضيفها للملفين.
- **الاختبارات:** `app/src/test/java/eu/kanade/manhwa/*Test.kt`، بـ JUnit5 + kotest.
  - **ممنوع `:` في اسم الاختبار**، لأنها بتكسر الكومبايل.
- **أخطاء كومبايل اتكررت:**
  - `import androidx.compose.ui.unit.dp` ناقص.
  - دالة `suspend` اتنادت من دالة عادية.
  - دالة اتشالت بالغلط مع helper قديم.

## 5. آخر تعديل بالتفصيل: مساعدين السرعة والموديلات (`c50c347e4`)

**الملفات:** `translation/local/ModelCatalog.kt`، و`LocalAiEngine.kt`، و`LocalAiTranslator.kt`، و`LocalModelsScreen.kt`، و`PhoneEnsemble.kt`، و`TranslationPreferences.kt`.

**الموديلات:**
- **`ModelCatalog.models`** = 3 بس، وكلهم gated، يعني لازم توافق على رخصة جوجل بالتوكن بتاعك:
  - Gemma 3n E4B (4.4GB): المترجم الأساسي.
  - Gemma 3n E2B (3.1GB): أخف، أو حَكَم.
  - Gemma 3 1B (0.55GB): المسودة.
- **`ModelCatalog.retired`** = Phi-4 mini، وQwen 2.5 3B، وQwen 2.5 1.5B:
  - بيظهروا في الشاشة بس لو فيه نسخة متحملة، ومعاهم زرار مسح ومن غير زرار تحميل.
  - التطبيق مش بيمسحهم لوحده.
- **`ModelCatalog.known`** = models + retired. ده اللي بيستخدمه PhoneEnsemble والشاشة، عشان الإعداد القديم ما يبوظش.

**ML Kit بيعمل المسودة الأول:**
- `translationLocalTuning` الافتراضي بقى `"AUTO"`، و`Tuning.named(x)` بيرجّع EDIT لأي قيمة غير `"FAST"`.
- EDIT معناه: ML Kit بيعمل مسودة لكل السطور، والموديل بيرد بـ "=" على السطر الصح ويكتب التصحيح بس.
- لو اختبار السرعة اتعمل قبل كده واختار FAST، اختياره بيفضل.
- موديل ML Kit بيتحمّل على أي شبكة (اتشال `requireWifi()`).

**NPU:**
- **فين:** `NpuSupport` و`NpuRules` في `LocalAiEngine.kt`، وجوه `create()`.
- **إزاي بيلاقيه:** `LlmInference.Backend.valueOf("NPU")` عن طريق reflection، فالكود بيتبني حتى لو المكتبة ما فيهاش NPU.
- **إمتى بيجربه:** على Qualcomm بس (`SOC_MANUFACTURER == "QTI"` أو `HARDWARE`/`BOARD` فيه "qcom").
- **أول مرة لكل ملف موديل:**
  1. يكتب `npu:<file>=failed` بـ `commit()` قبل التجربة، فلو الموبايل وقع، ما يتجربش تاني.
  2. يبني الموديل ويطلب "Reply with OK."
  3. لو نجح يكتب `works`. لو فشل يرجع للـ GPU، وبعده الـ CPU.
- **التخزين:** SharedPreferences `manhwa_models`.
- **مش متأكد** إن 0.10.27 فيها NPU (ما قدرتش أفتح dl.google.com). والـ NPU غالباً محتاج موديل متجهّز للشريحة نفسها.

**قراية القواعد مرة واحدة:**
- **إزاي:** `LocalAiEngine.generate(..., prefix = head)`.
  - كل Slot بيحتفظ بجلسة قرت الـ head (`prefixSession`).
  - كل طلب بينسخها بـ `cloneSession` (عن طريق reflection) ويضيف الباقي.
  - لو فيه أي خطأ، بيعمل `dropPrefix` ويقرا البرومبت كله.
- **الـ head** = أول سطر + قاعدة العربي + تعليمات المستخدم. القاموس والشخصيات والأمثلة والسياق والسطور بقوا بعد الـ head.
- **الفرق في السرعة صغير**، لأن الـ head قصير.

**كارت "السرعة على موبايلك":** بيعرض الـ backend الحالي (NPU أو GPU أو CPU)، ونصايح وضع الأداء في RedMagic. التطبيق ما يقدرش يشغّل وضع الأداء لوحده.

**النصوص الجديدة:** `speed_title`، و`speed_backend`، و`speed_backend_none`، و`speed_info`، و`speed_tips`.

**الاختبارات:** `PhoneSpeedTest` (جديد، بيختبر `NpuRules`)، و`PhoneCascadeTest` (اتحدّث عشان `Tuning.named`).
